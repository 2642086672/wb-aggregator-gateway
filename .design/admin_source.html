智能路由 智能别名 / 故障转移 / 失败冷却

智能别名：客户端请求 smart / cheap / vision / coding 时，按候选顺序自动选路，跳过冷却中的模型。
故障转移：主模型返回 retry_on 中的错误码时，自动尝试候选列表里的下一个模型；全部失败后返回最后一次上游错误。
冷却：模型失败后 cooldown_seconds 秒内不再优先选它，成功后自动恢复。
